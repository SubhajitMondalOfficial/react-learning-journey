# 🎨 Background Changer

A simple React project that changes the background color with a single button click.

## 🚀 Features

- Change background color instantly
- Built with React `useState`
- Styled using Tailwind CSS
- Smooth color transition

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS

## ▶️ Run the Project

```bash
npm install
npm run dev
```
