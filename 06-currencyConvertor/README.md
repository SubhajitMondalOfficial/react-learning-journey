# 💱 Currency Converter

A simple Currency Converter built with **React** and **Tailwind CSS**. This project allows users to convert amounts between different currencies using live exchange-rate data from an API.

## 🚀 Features

- Currency conversion using live exchange rates
- Select From and To currencies
- Swap currencies with one click
- Dynamic currency options
- Reusable InputBox component
- Custom React Hook for API fetching
- Responsive UI
- Modern Tailwind CSS design

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- Tailwind CSS
- Vite
- Fetch API

## 📚 React Concepts Practiced

- Functional Components
- Props
- Component Reusability
- `useState`
- `useEffect`
- `useId`
- Custom Hooks
- Controlled Inputs
- Event Handling
- API Integration
- Rendering Lists with `map()`
- Working with API Data
