# 💼 Job Portal UI

A modern Job Portal UI built with **React** using **Props** and **Reusable Components**. This project displays multiple job listings dynamically by passing data through props, making the code clean, scalable, and reusable.

## 🚀 Features

- Dynamic job listing cards
- Reusable React components
- Props-based data passing
- Responsive card layout
- Company logo, job title, salary, location, and tags
- Modern and clean UI
- Navigation Bar and Footer

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- CSS

## 📚 React Concepts Practiced

- Functional Components
- Props
- Component Reusability
- Rendering Lists with `map()`
- JSX
- Folder Structure

## 📂 Project Structure

```
src/
├── components/
│   ├── Navbar.jsx
│   ├── Card.jsx
│   └── Footer.jsx
├── App.jsx
└── main.jsx
```

## ▶️ Run the Project

```bash
npm install
npm run dev
```
